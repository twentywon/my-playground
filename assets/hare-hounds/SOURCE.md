# 토끼와 사냥개 이미지

온라인 OpenMoji 메타데이터에서 `rabbit`과 `dog`를 검색해 선택했습니다.

- 제작: [OpenMoji](https://openmoji.org/) — the open-source emoji and icon project
- 검색 목록: https://raw.githubusercontent.com/hfg-gmuend/openmoji/master/data/openmoji.json
- 토끼: https://openmoji.org/library/emoji-1F407/
- 개: https://openmoji.org/library/emoji-1F415/
- 라이선스: [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/). 전문은 LICENSE.txt.
- 취득일: 2026-11-08. 원본 SVG를 변경하지 않고 게임 말과 썸네일의 이미지 요소로 사용합니다. CSS 크기 조정 외에 원본 도안 편집은 없습니다.
- 원본 URL 및 체크섬은 sources.json에 기록했습니다. 오프라인 실행을 위해 동일한 SVG를 src/duel-images.js에 data URL로 포함합니다.
