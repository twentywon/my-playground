# Korean Hwatu SVG — online game artwork

Used in the public web-based Hwatu / Matgo / Go-Stop game:
https://github.com/itsent-lab/hwatu/tree/main/apps/web/public/cards/hwatu

Original artwork: **Spenĉjo** (individual SVG files), **Marcus Richert** (Korean Hwatu master design), based in part on Hanafuda graphics by **Louie Mantia, Jr.**

Original collection: https://commons.wikimedia.org/wiki/Category:SVG_Hwatu
Master overview: https://commons.wikimedia.org/wiki/File:Hwatu_overview.svg
License: **CC BY-SA 4.0** — https://creativecommons.org/licenses/by-sa/4.0/

Downloaded unchanged; only filenames renamed. Original SHA-1 values were verified against the online game's source metadata. `verification.json` records each card's individual source URL, original title, hashes and local filename. The images are embedded unchanged in `src/assets.js` for offline play. This license applies to the card artwork and its adaptations, not independently authored application code.

Months 1–10: variant 0 is the bright/animal card; variant 1 is the ribbon (August: geese). Only January, March and August have bright flags. These are assets from a public web game, not extracted commercial Hangame/Pmang client files.
